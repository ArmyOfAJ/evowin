The History Of Windows (1985-2026)

By: Arnav Jha

  • Windows 1.0, the first major release of Windows

    Windows 1.0 was released on November 20, 1985, for $99, running as a graphical shell atop MS-DOS. It featured a tiled window manager that prevented overlapping and included built-in programs like Paint, Write, and Reversi. Successive updates like 1.02 and 1.03 added international support and expanded hardware drivers before IBM PS/2 support arrived in version 1.04. Microsoft ended support on December 31, 2001.

  • Windows 2.0, the second major release of Windows

    Windows 2.0 released on December 9, 1987, for $100, introducing overlapping windows and the first versions of Word and Excel. It featured "Maximize/Minimize" controls and led to a landmark legal battle with Apple over its interface design. Support ended December 31, 2001.

  • Windows 2.1, the third major release of Windows

    Windows 2.1x launched in May 1988, splitting into Windows/286 and Windows/386 to leverage Intel 80386 multitasking. The 2.11 update refined drivers and speed. It proved Windows could handle professional multitasking before support ended on December 31, 2001.

  • Windows 3.0, the fourth major release of Windows

    Windows 3.0 launched on May 22, 1990, becoming the first version to achieve widespread commercial success with over 10 million copies sold. It introduced a revamped UI with 3D-style buttons, the Program Manager, and the File Manager. A significant 1991 update brought Multimedia Extensions, adding support for CD-ROM drives and sound cards, effectively starting the PC multimedia era.

  • Windows 3.1, the fifth major release of Windows

    Windows 3.1 released on April 6, 1992, for $149, refining the environment by requiring a 286 processor and dropping "Real Mode" support. It debuted the TrueType font system, making it a viable desktop publishing platform, and included the popular game Minesweeper. Networking features were significantly bolstered through the Windows for Workgroups sub-series before support ended in 2001.

  • Windows 95, the sixth major release of Windows

    Windows 95 arrived August 24, 1995, introducing the Start menu, taskbar, and Plug and Play. Later OSR updates added FAT32 and USB support. It merged MS-DOS and Windows into one product until support ended in 2001.

  • Windows 98, the seventh major release of Windows

    Windows 98 launched June 25, 1998, refining the 95 interface with Active Desktop and better USB support. Second Edition (SE) arrived in 1999 with Internet Connection Sharing. Support officially concluded on July 11, 2006.

  • Windows ME, the eight major release of Windows

    Windows Millenium Edition (or ME for short) released September 14, 2000, as the final 9x-based OS. It introduced System Restore and Movie Maker but was criticized for instability and restricted MS-DOS access. Support ended July 11, 2006.

  • Windows XP, the ninth major release of Windows

    Windows XP launched October 25, 2001, unifying consumer and business lines on the NT kernel. Featuring the "Luna" UI and built-in Firewall via SP2, it became one of Microsoft's most successful releases. Support finally ended April 8, 2014.

  • Windows Vista, the tenth major release of Windows

    Windows Vista released January 30, 2007, introducing Aero glass, User Account Control (UAC), and Instant Search. Despite its visual polish, high hardware demands led to a rocky reception. Extended support concluded on April 11, 2017.

  • Windows 7, the eleventh major release of Windows

    Windows 7 arrived October 22, 2009, as a streamlined version of Vista. It introduced the Aero Snap feature, a redesigned taskbar, and improved DirectX 11 graphics. It remained one of the most popular operating systems until extended support officially came to an end on January 14, 2020.

  • Windows 8, the twelfth major release of Windows

    Windows 8 arrived on October 26, 2012, for a retail price of $119.99 for the Pro version, famously replacing the Start menu with a touch-centric Start screen. It introduced the Metro design language, the Windows Store, and the Charms bar. Built for hybrid devices, it aimed to unify the tablet and desktop experience, though the removal of the Start button proved highly controversial among traditional PC users.

  • Windows 8.1, the thirteenth major release of Windows

    Windows 8.1 released on October 17, 2013, as a free update to address criticism of the original Windows 8. It re-introduced a visible Start button on the taskbar and the option to boot directly to the desktop. The update also improved OneDrive integration, added more tile sizes for the Start screen, and updated Internet Explorer 11, refining the "Metro" experience until extended support ended in 2023.

  • Windows 10, the fourteenth major release of Windows

    Windows 10 launched July 29, 2015, introducing "Windows as a Service," the Edge browser, and Cortana. It returned a hybrid Start menu and introduced Windows Hello. Support ended on October 14, 2025.

  • Windows 11, the fifteenth major release of Windows

    Windows 11 released October 5, 2021, featuring a centered taskbar, Mica design, and strict TPM 2.0 security requirements. It added Snap Layouts and AI Copilot, continuing as Microsoft's flagship OS.
